# Get started

This section takes you from an empty machine to a running Codenotch project in about fifteen
minutes. You install the tools, create a project, run it on your machine, and change it.

## What you need

- A computer with macOS on Apple silicon, Linux (x64) or Windows (x64).
- Node.js 22.13 or later, with npm.
- Basic knowledge of TypeScript and React.

## The steps

1. [Install the tools](install.md): the `cn` command, the local runtime, and the VS Code
   extension if you use VS Code.
2. [Quickstart](quickstart.md): create a project, run it, add a process and call it from
   your app.
3. [Tour of a project](project-tour.md): what each file of a project is for.
4. [Explore the playground](playground.md): a sample project with one working example per
   feature.

## Terminal or VS Code?

Everything in this documentation works from a terminal with the `cn` command. The [VS Code
extension](../vscode/README.md) runs the same commands for you, with buttons, forms and
help while you type. You can use both: the extension calls `cn` behind the scenes.
